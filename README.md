# 노인교구 홈페이지 (firstmove)

5년간 다양한 관공서에 치매예방교구를 공급하는 스마트스토어 소개용 한 페이지 웹사이트입니다.

## 파일 구조
- `index.html` : 페이지 내용
- `css/style.css` : 디자인
- `js/main.js` : 애니메이션·메뉴·이메일 조합
- `images/` : 사진 (영문 소문자, 띄어쓰기 없이 저장)
- `netlify.toml` : Netlify 배포·보안 헤더 설정

## 내 컴퓨터에서 미리보기
`index.html`을 더블클릭하면 브라우저에서 열립니다.

## 나중에 채울 것 (index.html 안의 TODO 표시)
- 교구 이름·설명·사진 (교구 소개 카드)
- 활용사진 (gallery)
- 사무실 주소 (문의 섹션)
- 스마트스토어 주소 (버튼 추가)
- 치매예방 정보 문구 확인 (일반적인 생활 상식 초안입니다)
- 카카오톡 미리보기 이미지 (현재는 images/hero.jpg 사용, 1200×630 권장)
